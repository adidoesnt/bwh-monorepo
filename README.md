# bwh-monorepo

Monorepo for builtwithhabit, managed with [Turborepo](https://turborepo.dev) and [bun](https://bun.sh) workspaces.

## Apps and packages

| Path | Status | Description |
| :-- | :-- | :-- |
| `apps/website` | **Live** | The builtwithhabit marketing site and blog (Astro + Svelte islands, deployed on Vercel). See `apps/website/README.md`. |
| `apps/booking-portal` | 🚧 Not started | SvelteKit scaffold only — booking portal, development has not begun. |
| `apps/shop` | 🚧 Not started | SvelteKit scaffold only — shop, development has not begun. |
| `packages/ui` | Shared | Svelte components/icons shared across apps (`@repo/ui`). |
| `packages/tailwind-config` | Shared | Shared Tailwind CSS v4 / daisyUI config. |
| `packages/eslint-config` | Shared | Shared ESLint config. |
| `packages/typescript-config` | Shared | Shared `tsconfig.json` bases. |
| `plugins/bwh-blog` | Tooling | Claude Code plugin letting non-technical collaborators write and publish blog posts without git. See `plugins/bwh-blog/README.md`. |

`apps/booking-portal` and `apps/shop` are placeholder SvelteKit projects generated by `sv create` — no routes or features have been built yet. Treat them as reserved names/ports, not working apps.

## Commands

Run from the repo root:

| Command | Action |
| :-- | :-- |
| `bun install` | Install dependencies for all workspaces |
| `bun run dev` | Run `dev` in every workspace via Turborepo |
| `bun run dev:website` | Run only the website's dev server |
| `bun run dev:portal` | Run only the booking-portal's dev server |
| `bun run dev:shop` | Run only the shop's dev server |
| `bun run build` | Build all workspaces via Turborepo |
| `bun run lint` | Lint all workspaces via Turborepo |
| `bun run check-types` | Type-check all workspaces via Turborepo |
| `bun run format` | Format `.ts`/`.tsx`/`.md` files with Prettier |
| `bun run blog:write-post` | Write/import a blog post via the `bwh-blog` Claude Code plugin |
| `bun run blog:toggle-draft` | Publish/unpublish a blog post via the plugin |
| `bun run blog:publish` | Commit and push blog content changes via the plugin |
| `bun run blog:package` | Package `plugins/bwh-blog` into a distributable `.plugin` file |

You can target a specific workspace directly with Turborepo's `--filter`, e.g. `bunx turbo build --filter=website`.
